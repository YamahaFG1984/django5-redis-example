2启动 Redis 服务

在 docker-compose.yml 里加一个 redis 服务，并给 Django 服务加上 REDIS_URL 环境变量。容器之间通过服务名 redis 访问。

  redis:
    image: redis:7.4-alpine
    restart: always
    # appendonly: 开启 AOF 持久化，每秒刷盘一次，重启后数据还在
    command: redis-server --appendonly yes --appendfsync everysec
    ports:
      - "6379:6379"
    volumes:
      - ./data/redis:/data
RDB 还是 AOF？

Redis 默认使用 RDB 快照（隔一段时间把整个数据集写到磁盘），两次快照之间的数据宕机就丢了。本项目里点赞、关注、签到只存在 Redis（见设计文档「模式 C」），所以开启 AOF。生产环境一般两者同时开启：AOF 保证尽量少丢数据，RDB 用来备份和快速恢复。

3连接池：redis_client.py

3.1 为什么需要连接池

每次请求都新建 TCP 连接的话，三次握手和认证的耗时往往比执行命令本身还长。连接池在进程内维护一组已经建好的连接，用的时候借出，用完归还。

3.2 代码

"""
Redis 连接管理。

整个进程共享一个连接池（ConnectionPool）。get_redis() 每次返回一个新的
Redis 对象，但它很轻量，真正的 TCP 连接由连接池负责复用。
"""
import redis
from django.conf import settings
from django.core.signals import setting_changed
from django.dispatch import receiver

_pool = None


def get_redis():
    global _pool
    if _pool is None:
        _pool = redis.ConnectionPool.from_url(
            settings.REDIS_URL,
            # 让命令返回 str 而不是 bytes，模板和业务代码里更方便
            decode_responses=True,
        )
    return redis.Redis(connection_pool=_pool)


def reset_pool():
    """断开并丢弃连接池，下次 get_redis() 时按最新配置重建。"""
    global _pool
    if _pool is not None:
        _pool.disconnect()
    _pool = None


@receiver(setting_changed)
def _on_setting_changed(setting, **kwargs):
    # 测试里用 override_settings 切换 REDIS_URL 时，让连接池跟着切换
    if setting == 'REDIS_URL':
        reset_pool()
  • 延迟创建：第一次调用 get_redis() 时才创建连接池，导入模块时不会连接 Redis。
  • decode_responses=True：redis-py 默认返回 bytes（b'42'），开启后返回 str。代价是二进制数据（比如用 GET 读 Bitmap）不能再直接读取，第 7 章会遇到，到时用 BITFIELD 解决。
  • 监听 setting_changed：测试里用 override_settings 把 REDIS_URL 换成 db15 时，连接池会自动重建。
为什么不用 django-redis？

django-redis 是常用的第三方库，但 Django 4.0 起已经内置了 RedisCache 后端（第 5 章使用）。对于业务数据，直接用 redis-py 能调用全部命令，学习时也更直观。

4Key 规范：redis_keys.py

"""
所有 Redis Key 的唯一出处。

命名规则：{前缀}:{实体}:{ID}:{属性}，例如 blog:post:42:views
业务代码里不要手写 Key 字符串，统一调用这里的函数。
每一章新增的 Key 都追加在本文件中，读这个文件就能知道 Redis 里存了什么。
"""
from django.conf import settings


def _k(*parts):
    return ':'.join([settings.REDIS_KEY_PREFIX, *map(str, parts)])


# ---------------------------------------------------------------- step-03 浏览量
def post_views(post_id):
    """STRING  文章 PV 计数"""
    return _k('post', post_id, 'views')


def post_uv(post_id):
    """HYPERLOGLOG  文章 UV（独立访客数）"""
    return _k('post', post_id, 'uv')


def post_seen(post_id, visitor_id):
    """STRING  防刷标记：某访客最近看过某文章，TTL 30 分钟"""
    return _k('post', post_id, 'seen', visitor_id)


def post_views_dirty():
    """SET  浏览量有变化、等待回写数据库的文章 ID"""
    return _k('post', 'views', 'dirty')


# ---------------------------------------------------------------- step-04 排行榜
def rank_total():
    """ZSET  总榜：member = 文章 ID，score = 浏览次数"""
    return _k('rank', 'views', 'total')


def rank_daily(day):
    """ZSET  日榜，TTL 8 天"""
    return _k('rank', 'views', 'day', day.strftime('%Y%m%d'))


def rank_weekly(day):
    """ZSET  截止到 day 的 7 天榜（7 个日榜的并集），缓存 5 分钟"""
    return _k('rank', 'views', 'week', day.strftime('%Y%m%d'))

这一章只有一个辅助函数 _k()。从下一章开始，每个功能都会在这里添加自己的 Key 函数，例如：

def post_views(post_id):          # step-03
    return _k('post', post_id, 'views')      # blog:post:42:views

def rank_daily(day):               # step-04
    return _k('rank', 'views', 'day', day.strftime('%Y%m%d'))

5测试基类：RedisTestCase

测试直接连真实的 Redis，不用 mock，这样测的就是真实命令的行为。为了不影响开发数据，测试用 db15，并在每个用例开始前清空：

from urllib.parse import urlparse, urlunparse

from django.conf import settings
from django.test import TestCase, override_settings

from blog.redis_client import get_redis


def _with_db(url, db):
    """把 redis://host:6379/0 换成 redis://host:6379/{db}"""
    return urlunparse(urlparse(url)._replace(path=f'/{db}'))


TEST_REDIS_URL = _with_db(settings.REDIS_URL, 15)


@override_settings(REDIS_URL=TEST_REDIS_URL)
class RedisTestCase(TestCase):
    """
    连接真实 Redis 的测试基类。

    使用 db15，避免误删开发数据；每个用例开始前清空，保证用例之间互不影响。
    """

    def setUp(self):
        super().setUp()
        self.redis = get_redis()
        self.redis.flushdb()


def make_user(username='alice'):
    from django.contrib.auth import get_user_model

    return get_user_model().objects.create_user(username, password='redis123')


def make_post(title='Hello Redis', author=None, tags=(), **fields):
    from django.utils.text import slugify

    from blog.models import Post

    post = Post.objects.create(
        title=title,
        slug=slugify(title),
        author=author or make_user(f'author-{slugify(title)}'),
        body='Demo body',
        status=fields.pop('status', Post.Status.PUBLISHED),
        **fields,
    )
    if tags:
        post.tags.set(tags)
    return post

class RedisSetupTests(RedisTestCase):
    def test_uses_test_database(self):
        kwargs = get_redis().connection_pool.connection_kwargs
        self.assertEqual(kwargs['db'], 15)
        self.assertTrue(TEST_REDIS_URL.endswith('/15'))

    def test_ping_and_decode_responses(self):
        r = get_redis()
        self.assertTrue(r.ping())
        r.set('hello', 'redis')
        # decode_responses=True，返回 str
        self.assertEqual(r.get('hello'), 'redis')

    def test_get_redis_shares_one_pool(self):
        self.assertIs(get_redis().connection_pool, get_redis().connection_pool)

    def test_key_prefix(self):
        self.assertEqual(K._k('post', 1, 'views'), 'blog:post:1:views')
