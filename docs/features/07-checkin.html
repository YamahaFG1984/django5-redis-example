每日签到：Bitmap 存日历，Hash 存统计

签到是 Bitmap 的典型场景：每天只有「签了 / 没签」两种状态，正好用 1 个 bit 表示。这一章用两个维度的 Bitmap 分别记录「个人月历」和「全站每天谁签到了」，再用一个 Hash 记录跨月的连续天数和积分。

本章目标

  • 理解 Bitmap 的位布局和内存优势
  • 用 SETBIT 的返回值实现「每天只能签一次」
  • 用 BITFIELD 一次读出整月，用 BITOP 做跨天统计
  • 用 HASH 保存跨月的连续天数和积分

场景分析

PRD F5：每天只能签到一次；显示本月日历、本月天数、连续天数（跨月要连上）、累计天数和积分；显示今天全站签到人数和最近 7 天全勤人数。

Bitmap 是什么

Redis 没有单独的 Bitmap 类型，它就是一个 STRING，只是用 SETBIT / GETBIT / BITCOUNT 等命令按位读写。offset 从 0 开始，offset 0 是第一个字节的最高位。

为什么还要一个 Hash

Bitmap 按月拆分，所以跨月的连续签到（10 月 31 日 → 11 月 1 日）只靠 Bitmap 不好算，需要同时读两个月的 Key。另外累计天数、积分这些数字也需要一个地方存。一个用户的这几项统计放在同一个 Hash 里最合适：

def checkin_month(user_id, day):
    """BITMAP  用户某月的签到日历：offset = 日期 - 1，TTL 400 天"""
    return _k('checkin', user_id, day.strftime('%Y%m'))


def checkin_daily(day):
    """BITMAP  某天全站的签到情况：offset = 用户 ID，TTL 40 天"""
    return _k('checkin', 'day', day.strftime('%Y%m%d'))


def checkin_full_week(day):
    """BITMAP  临时结果：截止 day 连续 7 天都签到的用户（BITOP AND），TTL 60 秒"""
    return _k('checkin', 'week', day.strftime('%Y%m%d'))


def user_checkin_stats(user_id):
    """HASH  签到统计：total_days / streak / last_date / points"""
    return _k('user', user_id, 'checkin')

签到流程

★ 读-改-写为什么没有并发问题

_update_stats 先 HGETALL 再 HSET，本来是典型的竞态写法。但同一用户同一天只有一个请求能拿到 SETBIT 返回的 0，其他请求在前一步就返回了，所以 SETBIT 相当于起到了锁的作用。

读取：BITFIELD、BITCOUNT、BITOP

一次读出整月日历

逐天 GETBIT 要 31 次调用。BITFIELD key GET u31 0 把从 offset 0 开始的 31 位当作一个无符号整数一次读出来，再在 Python 里拆位：

⚠ 为什么不用 GET 读整个 Bitmap

连接池设置了 decode_responses=True（见第 2 章），GET 会尝试把 4 个字节按 UTF-8 解码成字符串，二进制数据通常会解码失败。BITFIELD 返回的是整数，没有这个问题。

只用 Bitmap 算连续天数

streak_in_month 读取 1 号到今天的位，从最低位（今天）往高位数连续的 1。缺点有两个：跨月需要再读上个月的 Key；今天还没签到时结果是 0。这正是本项目用 Hash 记录连续天数的原因。两种做法都保留在代码里，可以对比。

def streak_in_month(user_id, day=None):
    """
    只用 Bitmap 计算「本月内截止今天」的连续签到天数：
    取出 1 号到今天的位，从最低位（今天）开始数连续的 1。
    """
    day = day or timezone.localdate()
    value = (
        get_redis().bitfield(K.checkin_month(user_id, day))
        .get(f'u{day.day}', 0)
        .execute()[0]
    )
    streak = 0
    while value & 1:
        streak += 1
        value >>= 1
    return streak

def check_in(user_id, day=None):
    """
    签到。今天已经签过返回 None；否则返回 {'streak': 连续天数, 'points': 本次获得积分}。
    """
    day = day or timezone.localdate()
    r = get_redis()
    month_key = K.checkin_month(user_id, day)
    daily_key = K.checkin_daily(day)

    pipe = r.pipeline()
    # SETBIT 返回这一位原来的值：0 表示今天第一次签到
    pipe.setbit(month_key, day.day - 1, 1)
    pipe.expire(month_key, MONTH_TTL)
    pipe.setbit(daily_key, user_id, 1)
    pipe.expire(daily_key, DAILY_TTL)
    already_checked_in = pipe.execute()[0]
    if already_checked_in:
        return None
    # 同一用户同一天只有一个请求能走到这里，所以下面的读-改-写不会有并发问题
    return _update_stats(r, user_id, day)
def _update_stats(r, user_id, day):
    key = K.user_checkin_stats(user_id)
    stats = r.hgetall(key)
    yesterday = (day - timedelta(days=1)).isoformat()
    if stats.get('last_date') == yesterday:
        streak = int(stats['streak']) + 1   # 昨天签过：连续天数 +1（跨月也成立）
    else:
        streak = 1                          # 断签了，从 1 重新开始
    points = POINTS_PER_DAY
    if streak % STREAK_BONUS_EVERY == 0:
        points += STREAK_BONUS

    pipe = r.pipeline()
    pipe.hset(key, mapping={'last_date': day.isoformat(), 'streak': streak})
    pipe.hincrby(key, 'total_days', 1)
    pipe.hincrby(key, 'points', points)
    pipe.execute()
    return {'streak': streak, 'points': points}

def month_calendar(user_id, day=None):
    """
    返回本月每一天是否签到：[True, False, ...]，长度 = 本月天数。
    BITFIELD GET u{N} 0 把前 N 位当作一个无符号整数一次读出来。
    """
    day = day or timezone.localdate()
    days_in_month = calendar.monthrange(day.year, day.month)[1]
    value = (
        get_redis().bitfield(K.checkin_month(user_id, day))
        .get(f'u{days_in_month}', 0)
        .execute()[0]
    )
    # offset 0（1 号）是最高位，offset N-1（月底）是最低位
    return [
        bool(value >> (days_in_month - d) & 1) for d in range(1, days_in_month + 1)
    ]
def full_week_count(day=None):
    """截止 day 连续 7 天每天都签到的人数：7 个日 Bitmap 按位与。"""
    day = day or timezone.localdate()
    r = get_redis()
    dest = K.checkin_full_week(day)
    days = [K.checkin_daily(day - timedelta(days=i)) for i in range(7)]
    pipe = r.pipeline()
    pipe.bitop('AND', dest, *days)
    pipe.expire(dest, 60)
    pipe.bitcount(dest)
    return pipe.execute()[-1]

边界与思考

⚠ 本实现的取舍
  • 按用户 ID 做 offset 的日 Bitmap：大小由最大的用户 ID 决定。ID 到 1 亿时，即使只有 1 人签到，这个 Key 也有 12.5 MB。ID 很大或者很稀疏时，可以换成 HyperLogLog（只要人数）或 SET。
  • 「今天」按 TIME_ZONE 计算，项目是 UTC。面向国内用户时应改成 Asia/Shanghai，否则早上 8 点前签到会算成前一天。
  • 积分只存在 Redis：积分属于用户资产，生产环境应该写入数据库，或者通过消息队列异步落库。
